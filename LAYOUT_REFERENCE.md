## 📱 Breakpoint Reference

```
Mobile First Approach:

/* Mobile: Default styles */
.section { padding: 2rem 1rem; }

/* Tablet: 768px+ */
@media (min-width: 768px) {
  .section { padding: 3rem 2rem; }
}

/* Desktop: 1024px+ */
@media (min-width: 1024px) {
  .section { padding: 5rem 4rem; }
}
```

## 🎯 Quick Reference: Mode Selection

### Use **System Mode** for:
- ✅ Grids and cards
- ✅ Navigation
- ✅ Skills and tools
- ✅ Achievement galleries
- ✅ Forms and inputs
- ✅ Any structured data display

### Use **Editorial Mode** for:
- ✅ About/bio sections
- ✅ Intro paragraphs
- ✅ Featured showcases
- ✅ Timeline stories
- ✅ Narrative content
- ✅ Call-to-action blocks

---

**Remember:** The layout system is designed to be flexible within constraints. System mode provides structure; Editorial mode provides expression. Together they create a cohesive identity.
